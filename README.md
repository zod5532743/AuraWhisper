## UltraWhisper Project README

# 🌟 UltraWhisper - Windows OS向けAI音声文字起こしシステム

## 📜 概要
本プロジェクトは、Windows環境に最適化されたネイティブなインターフェースを持つ、高性能な音声文字起こしアプリケーションです。単なる文字起こしに留まらず、録音から処理、そして結果の編集・校正までを一つのGUI上で完結させることを目指しています。

## ⚙️ システムアーキテクチャ
システムの動作は、以下の3つのレイヤーに分かれています。

1.  **Presentation Layer (GUI)**: `gui.py` (PyQt5)
    *   ユーザーが触れるインターフェース。録音開始、処理実行、キャンセルなど、ユーザーからの操作を受け付けます。
    *   処理の進捗（Progress）とエラー状態を、ステータスログにリアルタイムで分かりやすく表示します。
2.  **Workflow Layer (Worker)**: `BackendWorker` (QObject)
    *   GUIからの信号を受け取り、重い計算をメインスレッドから完全に分離し、非同期（Async）で実行を管理します。
    *   キャンセル要求（`CancelSignal`）のチェックポイントを各処理に組み込み、中断を可能にします。
3.  **Core Logic Layer (Backend)**: `audio_recorder.py`, `transcriber.py`
    *   **`audio_recorder.py`**: マイクデバイスとのI/O層を担い、音声データをキャプチャし、一時的な`.wav`ファイルとして保存する役割を持ちます。
    *   **`transcriber.py`**: Whisperモデルを用いて、音声ファイルからテキストに変換するAI処理の中核を担います。

## 🚀 実行手順
1. **環境構築**: 適切なライブラリのインストールが必要です。
   ```bash
   pip install PyQt5
   # 必要なAIライブラリも同様にインストールが必要です
   ```
2. **GUI起動**:
   ```bash
   python backend/gui.py
   ```
3. **ワークフロー実行**:
    *   GUI上で「🔴 録音開始」 $\rightarrow$ 「▶ 処理実行」の順でボタンを押します。
    *   ログの進捗バーに従い、処理を待機してください。

## ⚠️ ユーザーガイドライン
*   **キャンセル機能**: 処理中に「❌ 中止」ボタンを押すことで、途中のアクションを中断できます。
*   **エラーへの対応**: エラーが発生した場合、ログエリアに詳細なガイドが表示されます。基本的には「マイク接続の確認」や「ライブラリの再インストール」が必要です。
