# プロジェクト規定: AuraWhisper

このファイルは、AIエージェントが本プロジェクトで開発・対話を行う際の基本原則を定義します。

## 1. 言語と言語スタイル
- **対話と言語:** エージェントからの回答、解説、提案はすべて**日本語**で行ってください。
- **コードコメント:** コード内のコメントやDocstringも原則として**日本語**で記述してください。
- **トーン:** 簡潔かつ技術的に正確な表現を好みます。

## 2. 技術スタックと環境
- **OS:** Windows 11
- **主要言語:** Python, JavaScript (Electron), PowerShell
- **AI環境:** Ollama (Qwen2.5-Coder:14b, Qwen3.5:9b 等をローカル実行)
- **ツール:** Playwright MCP (ブラウザ自動化用)
- **エディタ:** VS Code

## 3. 開発ルール
- **モジュール化:** バックエンド（Python）とフロントエンド（Electron）の関心事を分離し、疎結合を保ってください。
- **エラー処理:** Windows環境特有のパス処理（バックスラッシュ等）や権限エラーを考慮した堅牢なコードを記述してください。
- **型定義:** Pythonでは型ヒント (Type Hints) を積極的に活用してください。
- **状況を5分毎に報告すること

## 4. コーディングにおける優先事項
1. **パフォーマンス:** GPUリソース（VRAM 12GB）を効率的に使用し、不要なCPU負荷を避ける実装を提案してください。
2. **継続性:** `RELEASE_NOTES_v1.1.0.md` に記載されている最新のアーキテクチャ（アプリ連動プロンプト、AMD DirectML対応等）との整合性を維持してください。
3. **ドキュメント:** 変更を加えた際は、関連する `.md` ファイルの更新案も併せて提示してください。

## 5. 禁止事項
- ユーザーの承諾なしに、既存の `config.json` や機密性の高い設定ファイルを大幅に書き換えないでください。
- 日本語以外の解説を行わないでください（コード内の標準的な英語表現は除く）。
- **[最優先指令] 全ての対話、解説、進捗報告は必ず日本語で行うこと。** 英語での回答は、たとえ1文であってもルール違反とみなします。

## ６．PDCA
既存のプログラム [AuraWhisper] を完成させるため、以下の手順で進めてください。

1. 【Plan】現状のコードを分析し、未実装機能と修正が必要なバグを特定してください。その後、実装完了までのマイルストーンを提示してください。
2. 【Do & Check】私がプランを承認したら、各マイルストーンを順に実装してください。実装のたびに必ず動作確認（テスト実行）を行い、成功したか失敗したかを報告してください。
3. 【Adjust】テストが失敗した場合は、自動的に原因を分析して修正を試みてください。3回試行しても解決しない場合は、私に指示を仰いでください。
4. 【Finish】全機能が完成したら、全体のコードレビューを行い、最終的な動作確認結果をまとめて報告してください。

まずは、手順1の分析とプランニングから始めてください。
LLMを含むとファイルが大きくなるので、ユーザーがダウンロードできるものは、インストール後にプログラムが起動してからインストールをする仕組みを入れてください（Whisper Large-v3 TurboやGPUのライブラリやpythonのライブラリ）
